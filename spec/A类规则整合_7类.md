## 2. G2 · HTTP 动词、状态码与错误码（5 条）

| # | 规则号 | M/O | 来源分类 | 规则标题（EN） | 中文要点 |
|---|--------|----|----------|----------------|----------|
| 1 | `STC-010-01-2507-2507-M` | M | Request verb and response status code | Standardize the use of HTTP verbs, facilitating developers to understand and use APIs correctly. | 动词规范：GET 取列表/单资源（200，必须安全幂等，单资源响应根用 {}）；POST 创建(201)/非CRUD(200)；PUT 更新或按 URL 创建（200/201，消息体须含完整信息、不得设默认值）；PATCH 局部更新(200，非幂等，可用 PUT 时不用)；DELETE 删除(200/204/202，必须幂等、不应带请求体)。 |
| 2 | `STC-020-01-2507-2509-M` | M | Request verb and response status code | When using the POST method for non-CRUD resource APIs, a verb must be used in the URI suffix. | 非 CRUD 操作（如启动/停止/备份）统一用 POST /resource/{id}/action 形式，动作动词放 URI 后缀。 |
| 3 | `STC-030-01-2507-2509-M` | M | Request verb and response status code | Batch Resource Operations | 批量操作统一 POST /v3/{resource}/batch-create\|batch-delete\|batch-update；全成功/全失败状态码与单资源一致，部分成功返回 207，异步返回 202 并提供状态查询接口；批量请求体为 resources 数组。 |
| 4 | `STC-040-01-2507-2507-M` | M | Request verb and response status code | Status codes must comply with the HTTP protocol specifications. | 响应状态码必须符合 HTTP 规范且与响应体语义一致（禁止失败时返回 200/掩错）；常用映射：参数错 400、未认证 401、无权限 403、资源不存在 404、限流 429、内部错 500；创建 201、异步受理 202、无实体 204、批量部分成功 207。 |
| 5 | `ERR-010-01-2507-2507-M` | M | Error Code | Unified Error Code Format and Error Response Body Format Specifications | 统一错误码规范：失败时响应体必须含应用级 error_code（服务缩写.数字码，同语义同码）+ error_msg；成功响应不得含 error_code/error_msg；错误详情可用 details 数组逐层展开（最外层在前）；IAM5.0 权限拒绝须带 encoded_authorization_message；底层/第三方错误信息要隐藏实现细节。 |

## 附：为什么单条目 A 是 33 条（58 − B/C 21 − DOC 3 − ASY→B 1）

- **58 条编号规则**中：单条目 A **33** 条、整篇级(DOC) **3** 条、B 档 **4** 条（原 VER-030/QUE-050/BAS-060 + 本次 ASY-010）、C 档 **18** 条两文档无证据。
- **DOC-010/020/030**：判定须整篇文档（统一模板/修订历史/跨版本迁移与 @deprecated），单条 API 条目无证据 → 整篇级单独处理，不入单条目 A。
- **ASY-010**：『异步接口须另提供按标识查状态/结果的接口』需跨接口聚合证伪 → 归 B 档。
- 其余 33 条：核心条款均可在**单条目内**读判（如 VER-010 的 URI 带 vX、STC-030 的批量动词/207/resources 数组、BAS-070 的入参易获取）；跨接口/流程次条款留 inapplicable/uncertain，不降级。
- 新 6 类内规则**全部不同、无重叠**；每类落在 5-6 条均衡区间，DOC/ASY 已不占位。
